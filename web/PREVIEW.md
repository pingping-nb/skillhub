# 落地頁預覽說明

## 如何檢視

1. 啟動開發伺服器：
```bash
cd web
npm run dev
```

2. 訪問 `http://localhost:5173`

## 頁面特性

### 動態效果
- 背景粒子動畫會自動執行
- 滑鼠懸停在特性卡片上會有縮放和顏色變化
- 按鈕有漸變和陰影效果
- 搜尋欄有光暈效果

### 響應式設計
- 移動端：單列布局，較小字型
- 平板：2列特性卡片
- 桌面：3列特性卡片，大標題

### 互動元素
- "探索技能" 按鈕 → 跳轉到搜尋頁面
- "發布技能" 按鈕 → 跳轉到發布頁面
- 搜尋欄 → 輸入後跳轉到搜尋結果
- 統計數字 → 懸停有漸變效果

## 與原首頁的區別

| 特性 | 原首頁 | 新落地頁 |
|------|--------|----------|
| 主要內容 | 技能列表（熱門/最新） | 產品介紹和特性展示 |
| 視覺風格 | 簡潔卡片式 | 科技感漸變 + 粒子動畫 |
| 配色 | 淺色為主 | 深色主題 + 霓虹色 |
| 目標 | 快速瀏覽技能 | 吸引新使用者瞭解產品 |
| 路由 | `/` | `/`（新），原首頁移至 `/skills` |

## 設計亮點

1. **粒子連線動畫**：80個粒子節點，距離小於120px時自動連線，透明度隨距離變化
2. **漸變文字**：標題使用 cyan → blue → violet 三色漸變
3. **光暈效果**：搜尋欄和背景有模糊的光暈裝飾
4. **分層動畫**：不同元素有不同的延遲時間，形成層次感
5. **懸浮互動**：卡片懸停時會上浮並顯示邊框高亮

## 技術細節

- 粒子系統使用 Canvas 2D API
- 動畫使用 CSS animations 和 transitions
- 響應式使用 Tailwind 的 breakpoint 系統
- 字型透過 Google Fonts CDN 載入
