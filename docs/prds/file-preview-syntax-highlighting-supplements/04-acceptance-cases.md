# 驗收測試用例：檔案預覽語法高亮

## 命名約定
- **AC-P**: 正向路徑 (Positive Path)
- **AC-E**: 錯誤路徑 (Error Path)
- **AC-B**: 邊界條件 (Boundary)
- **AC-S**: 安全測試 (Security)

---

## 正向路徑測試

### AC-P-001: Python 檔案語法高亮
- **前置條件**：使用者已登入，技能包含 Python 檔案（< 500KB）
- **步驟**：
  1. 開啟技能詳情頁
  2. 點選檔案樹中的 `main.py` 檔案
  3. 等待檔案預覽彈窗載入
- **預期結果**：
  - 顯示語法高亮的 Python 程式碼
  - 關鍵字（`def`, `class`, `import`）顯示為特定顏色
  - 字串顯示為特定顏色
  - 註釋顯示為特定顏色
  - 樣式與 Markdown 程式碼塊一致
- **相關約束**：BR-001, BR-007

### AC-E-002: 語法高亮渲染失敗
- **前置條件**：模擬 highlight.js 渲染異常

- **預期結果**：
  - 降級到純文字顯示
  - 顯示友好的錯誤提示："語法高亮載入失敗，已切換到純文字模式"
  - 複製和下載功能正常
  - 記錄錯誤日誌到控制檯
- **相關約束**：BR-004

### AC-E-003: 記憶體不足導致渲染失敗
- **前置條件**：模擬瀏覽器記憶體不足

  1. 開啟技能詳情頁
  2. 點選檔案樹中的大檔案（接近 500KB）
  3. 觸發記憶體不足異常（透過測試 mock）
- **預期結果**：
  - 降級到純文字顯示
  - 顯示提示："檔案較大，已切換到純文字模式以節省記憶體"
  - 複製和下載功能正常
- **相關約束**：BR-005

### AC-E-004: 網路請求失敗

## 安全測試

### AC-S-001: XSS 防護（惡意 HTML 標籤）

  2. 開啟技能詳情頁
  3. 點選檔案樹中的該檔案
  4. 觀察是否執行指令碼

  - 不執行任何指令碼
