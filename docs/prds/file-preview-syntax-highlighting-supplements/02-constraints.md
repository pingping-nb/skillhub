# 約束規範：檔案預覽語法高亮

## 1. 功能邊界

### 本次發布包含
- 常見程式語言語法高亮（Python, Shell, Java, JS/TS, Go, Rust, C/C++, Ruby, PHP）
- 配置檔案語法高亮（JSON, YAML, TOML, XML）
- 檔案大小閾值控制（500KB 語法高亮閾值，1MB 預覽上限）
- 錯誤降級處理（無法識別語言、渲染失敗時顯示純文字）
- 主題自動切換（跟隨系統 dark/light 模式）
- 複製程式碼按鈕（複用現有實現）

### 明確排除
- ❌ 行號顯示
- ❌ 程式碼摺疊/展開功能
- ❌ 語法錯誤檢測和提示
- ❌ 程式碼搜尋和跳轉
- ❌ 自定義語法高亮主題
- ❌ 程式碼編輯功能
- ❌ 程式碼格式化
- ❌ 虛擬滾動（大檔案分頁載入）

### 未來可能性（不在本次實現）
- 行號顯示（使用者反饋後考慮）
- 程式碼摺疊（長檔案場景）
- 自定義主題配置（使用者偏好設定）
- 更多語言支援（按需新增）
- 程式碼片段分享（生成連結）

## 2. 業務規則

| 規則 ID | 描述 | 觸發條件 | 預期行為 | 優先順序 |
|---------|------|---------|---------|--------|
| BR-001 | 檔案大小閾值控制 | 檔案大小 > 500KB | 顯示純文字（無語法高亮） | Must |
| BR-002 | 檔案預覽上限 | 檔案大小 > 1MB | 僅顯示下載按鈕，不預覽 | Must |
| BR-003 | 語言識別失敗降級 | 無法識別檔案語言 | 顯示純文字，不報錯 | Must |
| BR-004 | 渲染失敗降級 | 語法高亮渲染失敗 | 降級到純文字顯示 | Must |
| BR-005 | 記憶體不足降級 | 瀏覽器記憶體不足 | 降級到純文字顯示，顯示提示 | Should |
| BR-006 | 主題跟隨系統 | 使用者切換系統主題 | 語法高亮主題自動切換 | Must |
| BR-007 | 樣式一致性 | 所有程式碼渲染 | 與 Markdown 程式碼塊樣式一致 | Must |
| BR-008 | 複製功能保留 | 使用者點選複製按鈕 | 複製完整檔案內容到剪貼簿 | Must |

## 3. 技術約束

### 效能約束
- **渲染時間**：500KB 檔案語法高亮渲染時間 < 500ms（P95）
- **首次載入**：檔案預覽首次載入時間 < 1s（P95，包括網路請求）
- **記憶體佔用**：單個檔案渲染記憶體佔用 < 50MB
- **包體積**：新增程式碼包體積 < 100KB（gzipped）

### 相容性約束
- **瀏覽器支援**：
  - Chrome 90+
  - Firefox 88+
  - Safari 14+
  - Edge 90+
- **移動端**：支援響應式佈局，但不最佳化觸控互動
- **螢幕閱讀器**：基本可訪問性支援（程式碼內容可讀）

### 安全約束
- **XSS 防護**：使用 `dangerouslySetInnerHTML` 時確保 highlight.js 輸出已轉義
- **路徑遍歷防護**：複用現有的路徑驗證（禁止 `..` 和絕對路徑）
- **內容安全策略**：不允許使用者自定義語法高亮規則
- **敏感資訊**：不在前端快取檔案內容

### 可擴充套件性約束
- **語言擴充套件**：透過按需匯入語言包擴充套件，不影響初始包體積
- **主題擴充套件**：預留主題切換介面，當前僅支援系統主題
- **渲染器擴充套件**：CodeRenderer 元件設計為可替換（未來可切換到其他引擎）

## 4. 依賴關係

### 上游依賴
| 依賴項 | 版本 | 用途 | 風險 |
|--------|------|------|------|
| highlight.js | ^11.x | 語法高亮引擎 | 低（成熟穩定） |
| rehype-highlight | ^7.0.2 | Markdown 程式碼塊高亮（已有） | 低（已在使用） |
| react-markdown | ^10.1.0 | Markdown 渲染（已有） | 低（已在使用） |

### 下游影響
| 影響模組 | 影響型別 | 影響描述 | 緩解措施 |
|---------|---------|---------|---------|
| 檔案預覽彈窗 | 功能增強 | 新增語法高亮渲染邏輯 | 向後相容，不影響現有功能 |
| 檔案型別工具 | 功能擴充套件 | 新增語言對映函式 | 純新增，不修改現有函式 |
| 樣式系統 | 樣式複用 | 複用 Markdown 程式碼塊樣式 | 無影響，只讀取現有樣式 |

### 外部依賴
- **雲端儲存服務**：檔案內容讀取依賴 ObjectStorageService
- **後端 API**：`GET /api/v1/reviews/{id}/file?path={filePath}`
- **Redis**：後續最佳化階段用於快取（本次不實現）

## 5. 非功能性需求

### 可用性
- **錯誤提示**：渲染失敗時顯示友好的錯誤提示
- **載入狀態**：顯示 loading 狀態，避免使用者等待焦慮
- **降級體驗**：降級到純文字時不影響核心閱讀功能

### 可維護性
- **程式碼組織**：CodeRenderer 元件獨立，易於測試和替換
- **語言配置**：語言對映表集中管理，易於擴充套件
- **樣式管理**：複用現有樣式，減少維護成本

### 可測試性
- **單元測試**：CodeRenderer 元件和語言對映函式可獨立測試
- **整合測試**：檔案預覽流程可端到端測試
- **效能測試**：渲染時間和記憶體佔用可量化測試

### 可觀測性
- **錯誤日誌**：記錄語法高亮失敗的錯誤資訊
- **效能指標**：記錄渲染時間（透過 RUM）
- **使用者行為**：記錄檔案預覽使用情況（後續最佳化依據）
