# 使用者互動與社交

## 功能描述

SkillHub 提供了豐富的社交功能，讓團隊成員可以互動、分享、推薦技能包。

![概念圖](/diagrams/social-concept.png)

**核心功能**：

- **星標（Star）**：收藏喜歡的技能包，方便後續查詢
- **評分（Rating）**：給技能包打分（1-5 星），幫助其他人判斷質量
- **下載統計**：記錄下載次數，展示熱門技能包
- **通知系統**：及時接收稽核結果、評論回覆等通知

**社交資料**：

| 指標 | 說明 |
|------|------|
| **星標數** | 有多少人收藏了這個技能包 |
| **平均評分** | 所有使用者評分的平均值 |
| **下載量** | 累計下載次數 |
| **活躍度** | 最近更新時間、發布頻率 |

## 使用場景

**場景一：收藏常用技能包**

開發者發現一個好用的技能包，點選星標收藏。

![操作截圖](/screenshots/skill-detail-star.png)

**場景二：評分推薦**

使用技能包後，給出評分和評價，幫助團隊其他成員。

**場景三：檢視通知**

收到稽核透過的通知，或者有人評論了你的技能包。

![操作截圖](/screenshots/notifications.png)

**場景四：瀏覽熱門**

檢視星標數最多、評分最高的技能包，學習最佳實踐。

## 使用步驟

**星標技能包**：

1. 訪問技能包詳情頁
2. 點選「Star」按鈕
3. 技能包會出現在「我的收藏」列表中
4. 再次點選可以取消星標

**評分技能包**：

1. 訪問技能包詳情頁
2. 點選星星圖示選擇評分（1-5 星）
3. 評分會立即生效，影響技能包的平均評分
4. 可以隨時修改評分

**撰寫評價**：

1. 在已發布技能的詳情頁點選「寫評價」
2. 選擇 1-5 星並填寫最多 2000 字的評價
3. 可以修改或清空評價；清空評價不會刪除星級評分，即使技能之後取消發布也仍可清空自己的文字
4. 被管理員隱藏的評價在重新編輯後仍保持隱藏，只有技能管理員或超級管理員可以恢復公開

**檢視通知**：

1. 點選頂部導航欄的通知圖示
2. 檢視未讀通知列表
3. 點選通知跳轉到相關頁面
4. 標記為已讀或全部已讀

通知列表和未讀數每 10 秒透過普通 HTTP 請求重新整理，並在視窗重新獲得焦點時立即重新整理。舊版
`GET /api/v1/notifications/sse` 介面已移除；自建客戶端應改為輪詢
`GET /api/v1/notifications` 和 `GET /api/v1/notifications/unread-count`。

**檢視我的收藏**：

1. 訪問 `/dashboard/stars`
2. 檢視所有星標的技能包
3. 按星標時間、更新時間排序
4. 快速訪問常用技能包

## API 介面

**星標技能包**：
```bash
PUT /api/v1/skills/{skillId}/star
```

**取消星標**：
```bash
DELETE /api/v1/skills/{skillId}/star
```

**檢查星標狀態**：
```bash
GET /api/v1/skills/{skillId}/star
```

**響應示例**：
```json
{
  "starred": true,
  "starredAt": "2026-03-15T10:30:00Z"
}
```

**評分技能包**：
```bash
PUT /api/v1/skills/{skillId}/rating
Content-Type: application/json

{
  "score": 5
}
```

**引數說明**：
| 引數 | 型別 | 說明 |
|------|------|------|
| skillId | string | 技能包 ID（路徑引數） |
| score | number | 評分（1-5，必需） |

**獲取我的星標**：
```bash
GET /api/v1/me/stars?page=0&size=20
```

**獲取我的評分**：
```bash
GET /api/v1/skills/{skillId}/rating
```

**評價介面**：

```bash
# 公開評價列表
GET /api/v1/skills/{skillId}/reviews?page=0&size=20

# 檢視、建立或修改自己的評價
GET /api/v1/skills/{skillId}/reviews/me
PUT /api/v1/skills/{skillId}/reviews/me

# 清空評價文字並保留星級評分
DELETE /api/v1/skills/{skillId}/reviews/me

# 技能管理員或超級管理員隱藏、恢復評價
POST /api/v1/admin/skill-reviews/{reviewId}/hide
POST /api/v1/admin/skill-reviews/{reviewId}/restore
```

**響應示例**：
```json
{
  "score": 5,
  "ratedAt": "2026-03-15T10:30:00Z"
}
```

## 注意事項

> **評分規則**：每個使用者對每個技能包只能評分一次，可以修改評分但不能刪除。

> **評價規則**：只有已發布技能可以評價；公開列表只顯示可見評價。併發修改發生衝突時，重新整理詳情後重試。

- **星標數量**：技能包的星標數會顯示在搜尋結果和詳情頁
- **平均評分**：技能包的平均評分會影響搜尋排序
- **通知設定**：使用者可以在設定中關閉某些型別的通知
- **下載統計**：每次下載都會增加下載計數，用於熱門排序
