# 名稱空間管理

名稱空間是 SkillHub 中技能的隔離邊界和協作單元。

## 名稱空間型別

| 型別 | 字首 | 說明 |
|------|------|------|
| 全域性 | `@global` | 平臺級公共空間，由平臺管理員管理 |
| 團隊 | `@team-*` | 團隊/部門空間，由團隊管理員管理 |

## 建立名稱空間

1. 登入後進入"我的名稱空間"
2. 點選"建立名稱空間"
3. 填寫資訊：
   - 標識（slug）：URL 友好名稱
   - 顯示名：展示名稱
   - 描述：空間用途說明
4. 提交建立

## 名稱空間成員管理

### 新增成員

1. 進入名稱空間設定
2. 進入"成員管理"
3. 輸入使用者名稱搜尋
4. 選擇角色（OWNER/ADMIN/MEMBER）
5. 確認新增

### 角色變更

名稱空間 OWNER 或 ADMIN 可變更成員角色。

### 移除成員

名稱空間 OWNER 或 ADMIN 可移除成員。

## 名稱空間狀態

| 狀態 | 說明 |
|------|------|
| `ACTIVE` | 正常使用 |
| `FROZEN` | 凍結，只讀不可發布 |
| `ARCHIVED` | 歸檔，對外不可見 |
