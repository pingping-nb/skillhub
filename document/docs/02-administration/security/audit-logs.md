# 審計日誌

SkillHub 記錄所有關鍵操作的審計日誌，滿足企業合規要求。

## 審計範圍

記錄的操作包括：
- 技能發布、下載、刪除
- 稽核透過、拒絕
- 使用者登入、登出
- 許可權變更
- 名稱空間管理
- 配置變更

## 審計日誌查詢

透過管理後臺審計日誌頁面或 Admin API 查詢。

## 日誌欄位

- 操作時間
- 操作使用者
- 操作型別
- 目標資源
- 客戶端 IP
- User-Agent
- 請求 ID
- 詳細資訊
