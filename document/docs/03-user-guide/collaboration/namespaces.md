# 團隊名稱空間

## 加入名稱空間

需要名稱空間管理員邀請才能加入團隊名稱空間。

## 名稱空間角色

### MEMBER
- 可檢視名稱空間內所有技能
- 可發布技能（需稽核）
- 可收藏和評分

### ADMIN
- 所有 MEMBER 許可權
- 可稽核技能發布
- 可管理成員
- 可編輯名稱空間資訊

### OWNER
- 所有 ADMIN 許可權
- 可轉讓所有權
- 可歸檔名稱空間

## 技能可見性

| 可見性 | 說明 |
|--------|------|
| `PUBLIC` | 所有人可見，匿名可下載 |
| `NAMESPACE_ONLY` | 僅名稱空間成員可見 |
| `PRIVATE` | 僅 owner 和名稱空間 ADMIN 可見 |
