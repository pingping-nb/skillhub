# 提升到全域性

優秀的團隊技能可以申請提升到全域性空間，供全企業使用。

## 提升前提

- 技能在團隊空間已發布
- 申請人是技能 owner 或名稱空間 ADMIN
- 技能沒有待稽核的提升申請

## 申請提升

1. 進入團隊技能詳情頁
2. 點選"提升到全域性"
3. 填寫申請說明
4. 提交申請

## 稽核流程

1. 平臺管理員收到提升申請
2. 稽核技能質量和適用性
3. 稽核透過後：
   - 在全域性空間建立新技能
   - 保留原團隊技能
   - 記錄來源追溯關係

## 提升後

- 全域性空間的新技能獨立管理
- 原團隊技能繼續存在
- 兩者版本不自動同步
- 如需同步需手動操作
