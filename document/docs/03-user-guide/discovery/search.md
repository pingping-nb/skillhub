# 搜尋技能

## 全文搜尋

在搜尋框輸入關鍵詞，SkillHub 會在以下欄位中搜尋：
- 技能名稱
- 技能描述
- 技能 slug
- frontmatter 中除 `name`、`description`、`version` 外的其他欄位
- `keywords` / `tags` 等關鍵詞欄位

## 篩選條件

可透過以下條件篩選搜尋結果：
- 名稱空間
- 可見性
- 下載量排序
- 評分排序
- 更新時間排序

## 高階搜尋

使用搜尋語法：
- `namespace:@team-ai` - 指定名稱空間
- `category:code-review` - 指定分類
- `downloads:>100` - 下載量大於 100
