# 典型應用場景

## 企業內部技能共享

**場景描述**：企業內部多個團隊開發 AI 技能，需要一個集中的平臺進行共享和複用。

**解決方案**：
- 各團隊建立自己的名稱空間
- 技能在團隊內先稽核發布
- 優秀技能可申請提升到全域性空間
- 所有操作有完整審計記錄

**價值**：
- 避免重複開發
- 促進最佳實踐傳播
- 保障質量可控

## AI 技能治理與合規

**場景描述**：金融、政務等行業對 AI 應用有嚴格的合規要求，需要完整的稽核和審計機制。

**解決方案**：
- 雙層稽核流程（團隊稽核 + 平臺稽核）
- 細粒度 RBAC 許可權控制
- 完整的操作審計日誌
- 技能版本可追溯、可撤回

**價值**：
- 滿足合規要求
- 風險可控
- 責任可追溯

## 多團隊協作開發

**場景描述**：大型組織中多個團隊協作開發，需要清晰的許可權邊界和協作機制。

**解決方案**：
- 名稱空間隔離，團隊自治
- 名稱空間成員角色管理
- 技能可見性控制（公開/名稱空間內/私有）
- 團隊技能可申請提升到全域性

**價值**：
- 權責清晰
- 協作高效
- 安全可控

## CLI 工具整合

**場景描述**：已有使用 ClawHub CLI 的工作流，希望無縫遷移到 SkillHub。

**解決方案**：
- 提供 ClawHub CLI 協議相容層
- 透過 `/.well-known/clawhub.json` 自動發現
- 現有 CLI 工具無需修改即可使用
- 同時提供 SkillHub 自有 CLI 增強功能

**價值**：
- 保護現有投資
- 遷移成本低
- 漸進式升級
